# AI-агенты

В пакете два уровня документации для агентов.

## Для проектов-потребителей

Файл: `resources/agent/BITRIX24.md`.

Опубликовать в проект:

```bash
php artisan bitrix24:agent-docs
# .ai/bitrix24.md + подсказка, что добавить в AGENTS.md
```

Или вывести в stdout:

```bash
php artisan bitrix24:agent-docs --stdout
```

Файл содержит:

- установку через VCS;
- переменные окружения;
- золотые правила;
- шпаргалку API;
- рецепты;
- таблицу ошибок;
- особенности данных Bitrix;
- тестирование через `Bitrix24::fake()`;
- чек-лист задачи.

Не перезаписывай корневой `AGENTS.md` проекта: добавь в него ссылку
`@.ai/bitrix24.md` или строку с путём к файлу.

## Для разработки самого пакета

Файл: `AGENTS.md` в корне репозитория. Он описывает архитектуру, инварианты,
команды проверки и правила изменения публичного API.
